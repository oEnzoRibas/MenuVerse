# Código de conduta

Issues, revisões de código e discussões do MenuVerse são espaços para colaboração. Acolha perguntas, dê crédito a quem contribuiu e concentre críticas na proposta ou no comportamento do software.

Assédio, discriminação, ataques pessoais e divulgação de dados privados violam este código. Para pedir moderação, procure o mantenedor por um canal privado já estabelecido. Se precisar combinar esse contato, abra uma issue solicitando um canal privado e reserve os detalhes para a conversa com o mantenedor.

O mantenedor pode moderar comentários e restringir a participação conforme as ferramentas do GitHub e a gravidade do caso. Para falhas de segurança do software, consulte a [política de segurança](SECURITY.md).
