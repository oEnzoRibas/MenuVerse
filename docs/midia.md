# Demonstração e créditos de mídia

Desenvolvimento do MenuVerse por [oEnzoRibas](https://github.com/oEnzoRibas). O vídeo completo encerra com o crédito **Developed by oEnzoRibas**.

## Gravação do Brasa & Co.

A gravação acompanha um pedido fictício de R$ 48,90. O cliente escolhe o Brasa Original duplo com bacon e sem picles, confere o total e confirma a retirada. O pedido aparece no painel administrativo. Na cozinha, a equipe inicia a preparação e marca o pedido como pronto. O cliente vê o novo status na tela de acompanhamento.

| Arquivo                                  | Especificações                                              | Uso                            |
| ---------------------------------------- | ----------------------------------------------------------- | ------------------------------ |
| [Vídeo completo](media/demo.mp4)         | 40,44 s · 1280 × 720 · H.264 · 25 fps · sem áudio · 3,06 MB | Apresentação do fluxo completo |
| [Prévia animada](media/demo-preview.gif) | 11,8 s · 928 × 522 · 10 fps · loop contínuo · 2,72 MB       | Prévia exibida no README       |

O fluxo foi gravado com Playwright em uma sessão demonstrativa isolada, usando o nome fictício **Cliente Demo**. A edição e a compressão foram feitas com FFmpeg. A animação do GIF e a reprodução do MP4 pelo link do README foram verificadas no navegador com uma renderização local em GitHub Flavored Markdown.
