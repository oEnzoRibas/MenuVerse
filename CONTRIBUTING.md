# Contribuição

Execute `npm ci` e `npm run dev`. Use a demonstração para desenvolver sem depender de credenciais. Ao modificar o banco, acrescente uma migração em `supabase/migrations` e execute os testes SQL.

Antes do pull request, rode `npm run format`, `npm run lint`, `npm run typecheck`, `npm test`, `npm run test:e2e` e `npm run build`. Descreva o comportamento alterado e, para mudanças visuais, inclua capturas de desktop e mobile.
